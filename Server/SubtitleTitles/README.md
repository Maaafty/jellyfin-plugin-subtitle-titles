# mReel Media Inspector · mReel 媒体识别（Jellyfin 10.11.11）

mReel 的 Jellyfin 配套插件。服务器端识别字幕轨，默认只生成预览。开启写入后，只改 Jellyfin 的 `MediaStream.Title`；不改媒体文件、语言字段、默认 / 强制 / SDH 标志，不转码视频、不生成外挂副本。mReel 只在原文件直播放且轨道索引和字幕格式均匹配时采用 Jellyfin 的标题，避免把名字套到 HLS 或 ISO 的其他轨道上。

## 安装

此安装包针对 **Linux x86_64 的 Jellyfin 10.11.11**（包括 fnOS 上的 Docker 版）。包含 fastText 语言模型、OpenCC 和简繁字典、Tesseract 及简中／繁中／英文模型，不必另装系统包，不必重建 Jellyfin 镜像。语言识别在服务器本地完成；插件使用 Jellyfin 自带的 FFmpeg。

1. 在 Jellyfin「控制台 → 插件 → 仓库」添加发布方提供的 `manifest.json` URL。
2. 在「插件目录」安装 **mReel Media Inspector**，然后重启 Jellyfin。旧名称为 **Mafty Media Inspector**（更早叫 **Mafty Subtitle Titles**）。插件 ID、配置文件和扫描缓存不变，直接更新，不必卸载旧版或重加仓库。
3. 打开插件页面，展开「扫描设置」。在 **Language / 语言** 里选「中文」或保留自动，再选一个测试库，保留「仅预览」，按「运行字幕任务」。图片字幕抽样默认关闭，按需启用；任务完成后按「刷新结果」。
4. 核对后可选 **Apply suggested titles** 再运行；要撤销则选 **Restore original titles**。只处理当前标题仍匹配记录的轨道，不会覆盖后来手工改过的标题。
插件在写入 Jellyfin 前保存原标题和写入目标。改名记录不随识别缓存失效而丢弃；只改文件时间或新增外挂不会挡住恢复。恢复要求当前轨道能唯一匹配改名记录，且当前标题仍是插件写入的值。旧版记录只在能核对片源和轨道时迁移；已经无法核对的旧改名不会猜测恢复。

插件页面沿用 Jellyfin 主题。扫描设置可以收起；原有的媒体库勾选、语言、任务模式和扫描任务都保留。

「字幕识别结果」按 Jellyfin 的电影、剧集海报展示，可搜索、翻页。点击海报，在右侧（手机上为下方）查看字幕；剧集或多版本影片可切换集数和片源。对有扫描记录的片源，详情列出 Jellyfin 当前的全部字幕轨道和当前标题，区分改名待应用、已应用、手动修改、证据不足、跳过、失败和未扫描。跳过或失败时显示原因，不拿旧建议充当本次结果。浏览不会启动扫描。
特效状态和语言识别分开。ASS/SSA 会显示「未发现可检测的 ASS 效果」「少量 ASS 效果」或「完整特效」；图片字幕（PGS、VobSub、DVB、XSUB）显示「未检测特效」，即使已经识别出语言也不会把它当作无特效。这个状态可直接从已有缓存展示，不会触发 OCR 或改名。

语言识别后统一放在标题开头，例如「中文」变为「简英双语」，而「[字幕组] 校对版」变为「简英双语 · [字幕组] 校对版」。通用名称直接替换，署名、版本和任意其他自定义文字保留。已有明确的简繁或双语信息不会因识别结果较粗而丢失；简繁冲突不写入。无法识别语言时保留原标题的语言信息，`BeanSub-SC` 这类明确后缀仍可作为补充，但不会单凭它推断双语。经确认的完整特效独立标记，不重复添加。
命名会拆开明确的语言标签和版本说明：`TX-CHS/ENG` →「简英双语」，`简日双语[Kamigamisubs]` →「简日双语 · [Kamigamisubs]」，`English (SDH)` →「英语 · SDH」。斜杠、加号、并列方括号等分隔的多语标签也用同一规则，只删除新标题已表达的语言，不删字幕组、版本、SDH、强制或评论说明。含义不明的文字保留；检测与明确标签冲突时保留原标题。Mafty 客户端在同片源的字幕仍同名时，会在菜单中临时添加版本编号；编号不写回 Jellyfin。

标准语种名称、ISO 三字母别名和语言的本国语名称来自 .NET 的全球化数据（Linux 使用 ICU）。例如 `日本語 [SDH]` →「日语 · [SDH]」。插件只在明确的标签边界识别别名，不从字幕组名称中截字；`SDH`、`CC` 等字幕用途标记不当作语种。
「字幕」或 `subtitle(s)` 只是通用后缀，去掉后能识别为语言标签才合并，例如「英文字幕」→「英语」。去掉后不是语言标签的原标题不会删减，例如「导演评论字幕」。
常见双语缩写（如「简英」）和 `中文(簡)x日文` 这样的组合也先拆成语言；`x` 或 `×` 两侧都能识别为语言才会当作分隔，不删除字幕组联名。
同一个语言列表内若同时声明简体和繁体（如 `简体中文 / 繁体中文`），会标记为冲突并保留原标题。`zh-HK`、`zh-TW` 等地区标签即使与 SDH、字幕组等说明一起出现，也会保留。

如果原标题只有国家名、内容只识别出一种语言，且 ICU 为该语言只列出这个地区，标题可省略国家名，例如 `Czechia` →「捷克语」。有多个地区版本的语言保留地区，带版本说明的原标题也不按这条规则删减。原标题仍可恢复。
原标题只有国家名时，不靠地名推断语言。如果国家名和轨道语言标签相符，但模型识别成该地区不匹配的另一种语言，预览标为冲突并保留原标题。写入模式只撤回插件自己此前写入的标题，不覆盖后来手动改过的标题。

原标题解析与字幕内容识别是独立步骤；标题只提供语言声明和版本说明，不会影响文本或 OCR 的检测结果。改名预览分别显示「原标题标注语言」和「识别出的语言」，再单独显示合并后的建议。命名规则更新后，字幕任务可以用已有识别缓存重算建议，不必为改标题重新识别字幕；原标题仍用于恢复。

升级后旧 PGS 开关不会自动启用新抽样任务。已有有效的 PGS 识别结果保留，旧文本字幕仍可沿用已有识别缓存。

运行按钮会先保存设置，再启动对应任务。设置页同时显示两个任务的状态；Jellyfin 的「计划任务」仍可用于配置定时运行。

Jellyfin 重新探测片源时可能恢复原标题。插件能复用未改变文件的检测记录；如设定计划任务，应安排在 Jellyfin 媒体库扫描之后，不与它并发。

## 剧集扫描优化

「同一季内复用相同规格的字幕识别结果」默认关闭。开启后，同一季、同目录、同容器的单片源正片剧集，同一内封轨道规格（编码、原语言、原标题、默认／强制／SDH 标记）在两集分别识别且结论一致后才复用。外挂、不可区分的轨道、样本不足或不一致只影响对应轨道；电影不参与复用。
任务在开始复用前检查所选剧集中仍有效的直接识别缓存；已知反例会阻止复用，不取决于影片的处理顺序。过期、失败或者本身是复用得到的记录都不作为直接证据。缺少语言列表的旧直接记录需要重新识别，不能由同季推断覆盖。

如果 Jellyfin 缺集号，插件只在文件名有单一、明确的 `S01E01` 编号且季号与 Jellyfin 一致时，用它判断同季复用和显示建议。特别篇、`S01E01-x02` 等多集文件和季号不一致的文件不走兜底；同一集的两个文件不会算作两集样本。不会写回 Jellyfin 集号、修改文件名或 NFO。

复用会跳过相应轨道的提取和识别，包括 OCR；如果还有其他内封轨道需要扫描，FFmpeg 仍要读取容器。「同季复用」会标在相关建议上；关闭后重跑可独立识别这些轨道。普通日志按片源列出扫描、复用、缓存及未复用原因，具体轨道变化在调试级别。

mReel 跨集记忆内封字幕时会同时核对完整版本标题和语言。下一集没有同一版本，或者旧记录不能确认原来选的是哪种译本时，字幕保持关闭，手动选一次即可重新记忆。外挂仍按文件名后缀匹配。字幕菜单的语言筛选也认「简英」「繁日」等未改名的双语缩写。

## 蓝光原盘版本与杜比视界

选择媒体库后直接点插件设置页的「识别光盘规格」。支持服务器可读的蓝光 ISO 和完整 BDMV 文件夹。不必去「计划任务」手动启动，也不会顺带运行字幕 OCR 或写入 Jellyfin 的轨道元数据。普通 MKV、MP4 的 Dolby Vision 仍由 Jellyfin 识别。

「媒体识别结果」→ 影片海报 → 选光盘片源 →「光盘规格」。即使没扫过字幕，也能查看原盘版本。盘内制作资料和 HDMV 标题导航支持的版本，与未确认的候选列表分开显示；这两种静态证据都不等于实播按过原盘菜单。使用同样的片段和入出时间的列表归为同一剪辑，仍保留列表编号和各自的结果，以免混用有区别的字幕、音轨或章节。

插件静态读取已知的 Sony `playlists.xml`、Warner / Pixelogic `bluray_project.bin`、`playbackconfig.xml` 和可直接解析的 HDMV 标题导航，不运行盘上的 Java。没有可信证据时提供候选，不把最长列表认作正片。光盘任务逐条探测有证据的列表；没有证据时只探测排序最靠前的候选。检测使用显式 `.mpls` 编号，确认 HEVC 主层、增强层及杜比视界 RPU 才标记 Profile 7；无法确认不代表片源没有杜比视界。旧的单列表缓存不沿用，可按需运行任务生成列表级结果。
影片的 Dolby Vision 规格不等于实际播放输出；播放信息分别展示两者。

mReel 的影片详情可以选择光盘版本。播放请求只允许读取选定列表和它引用的片段及索引；不会在读取失败时悄悄切到另一条列表。选定列表后，音轨和字幕由播放器从该列表读取，不套用 Jellyfin 默认列表的轨道编号。

## 打包和发布（维护者）

在开发机运行下列命令，URL 改成最终用于托管文件的地址。打包机需要 Docker、.NET SDK、Python 3.11 和 curl，普通安装者不需要这些工具。

```sh
python3 Server/SubtitleTitles/package.py https://你的下载站/mafty-subtitle-titles
```

把 `build/jellyfin-repository/` 中的 `manifest.json`、Linux x86_64 ZIP 和 `*-dependency-sources.tar` 一起放到该地址。用户添加的是 `manifest.json` 的 URL。依赖许可证和版本清单在 ZIP 的 `runtime/linux-x64/licenses/` 中；用户安装时不会下载源码归档。已有 ZIP 换发布地址时，用同一命令加 `--manifest-only`，不会更改已验证的 ZIP 文件。
版本化归档不会覆盖。要重打相同版本，使用新的 `--output` 目录；准备正式更新时递增版本号。安装包和依赖源码都构建成功后才会替换清单。Docker 构建会使用打包机的 CA 证书包；需要指定证书包时设置 `SSL_CERT_FILE`。

## 检测范围

支持服务器可读的普通视频容器、同目录文本外挂，以及启用抽样后的 PGS、VobSub/DVD、DVB 位图和 XSUB。MKV 的 zlib 压缩 PGS 也能识别；升级后，旧版未得出结论的内封 MKV 位图轨道会补扫，已有明确结果不因这项修复重扫。

蓝光 ISO 内封 PGS 使用同一个字幕任务和「抽样识别图片字幕」开关。先用 Jellyfin 的 FFprobe 核对播放列表及轨道，再按播放列表时间定位，按每个片段自己的时钟取样，避免片段时间戳重置时采错位置。只有播放列表和轨道映射可核对时才生成建议，不参与同季复用。读取和 OCR 都有限额，不挂载、不改 ISO。加密或无法核对的 ISO、BDMV 文件夹、远程流、烧录字幕和不可读的条目不处理。此功能不改变 mReel 对 ISO 播放轨道标题的匹配规则。

位图字幕沿用媒体库任务，一次只处理一轨。先按片长在 15%、35%、55%、75%、90% 附近短读，随后按每读入一字节得到的新图数量，优先续读高产片段；字幕变稀或重复时离开，空片段可以在同片段内换位置再探一次。不设目标图片数，不解码视频，不回退到全片扫描。没有索引的 `.sup` 仍只遍历受读量限制的外挂字幕文件本身；其他外挂也须能明确选中轨道。每轮 OCR 只加载一次模型，受读量、CPU 时间和超时保护。限速不是温控，服务器过热时请保持关闭。
外挂 `.sup` 顺序读取时会保留解码状态，只对窗口内显示的字幕图运行 OCR；VobSub 的 `.idx` 和 `.sub` 读取都计入同一预算。

位图语言判定不读取原标题，也不要求固定数量的图或文本行：将逐行 OCR 和语言模型的置信分数合并为证据权重，扣除重复文字，只把同一张图上的两种语言计作配对，并限制单个片段对总权重的贡献。一处有双语、其他片段无佐证，或存在可信但未配对的第二语言，都可能保留原名而不下结论。升级后，旧 ISO 与外挂 SUP 轨道只在启用图片字幕识别并再次运行字幕任务时按新逻辑更新证据；不会因为本次改动重扫其他已确认的位图或文本轨道。

首轮能确认中文但分不出简繁，才用安装包里的高精度 `tessdata_best` 复核。复核只读取同次采样暂存的字幕图（每轨最多 32 MiB），不再次读影片；结果只补充简繁，不增减首轮识别出的语种。复核仍不确定或失败时保留首轮结论。任务会补查旧缓存中尚未复核、且简繁不明的中文位图字幕；已判定的简繁结果不因这项功能重扫。

文本字幕逐行识别；ASS 保留同一时间段的独立对白行，SRT 保留字幕块内的换行。fastText 模型覆盖 176 种语言，但只有同一语言有足够多的可信对白，以及多种语言持续在同一字幕时段出现时，才会一起标出。偶发片头歌词不算双语。中文行用 OpenCC 另判简繁，标题保留「简英双语」「简日双语」等简称，其余组合列出各语种，例如「英语 / 西班牙语 / 法语」。只靠少量文字、或多语全部写成难以分割的同一行时可能无法判全。PGS 仍使用简中／繁中／英文 OCR，不套用文本字幕的多语覆盖范围。

ASS 的普通描边、阴影不算特效。单独淡入淡出或局部动画只算少量效果，不给标题加「特效」；动画、移动、绘图或卡拉 OK 至少覆盖 12 个不同开始时刻、占比达到 10%、且分布在字幕时间跨度的前中后三段，才按「完整特效」处理。这个判定是启发式，建议在真实片库预览抽查。升级后重跑字幕任务会按新规则重新判断旧记录；已应用的旧标签可通过应用新版建议纠正，原标题仍可恢复。
